## How every lab works
- **Objective** — what you'll be able to do afterwards
- **Steps** — do them, don't just read them
- **Prove it** — the evidence to save in `evidence/`. No evidence = not finished.
- **Going deeper** — optional stretch goals

```bash
mkdir -p labs/00-foundations/evidence
```

No AWS or costs in this phase — it's all local.
